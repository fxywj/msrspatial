# msrspatial documentation

This directory hosts the Sphinx / mkdocs sources for the API reference.

## Build locally

```bash
pip install -e ".[dev]"
pip install sphinx sphinx-rtd-theme
sphinx-apidoc -o docs/api src/msrspatial
sphinx-build -b html docs docs/_build
```

## Planned structure

- `index.md` – overview and quick start (mirrors README)
- `api/` – autogenerated from module docstrings
- `tutorials/` – executable notebooks
- `validation.md` – numerical agreement with the original analysis

> Until the first release, the authoritative usage documentation is `README.md`
> and `examples/selftest.py`.
